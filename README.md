# BodVod site

Public pages for the BodVod iOS app, served by GitHub Pages:

- [Privacy policy](https://taltrums.github.io/bodvod-site/privacy.html)
- [Terms of use](https://taltrums.github.io/bodvod-site/terms.html)
- [Support](https://taltrums.github.io/bodvod-site/support.html)

These files are generated. Edit PRIVACY.md, TERMS.md or site/ in the app's
repository, run `python3 site/build.py` there, and copy `site/public/` here.
